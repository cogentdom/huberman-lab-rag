A Retrieval-Augmented Generation (RAG) app that answers questions using Huberman Lab podcast transcripts.  
The project combines OpenAI embeddings, Redis vector search, and a Flask UI/API.

## Interface preview

![Huberman Lab RAG interface](https://cogentdom.wordpress.com/wp-content/uploads/2026/02/huberman-lab-rag-interface.png)

## Why this project

- Demonstrates an end-to-end RAG workflow from transcript ingestion to grounded responses
- Uses production-style vector indexing with `redis-stack` and RediSearch
- Includes local and Docker-based runtime paths
- Shows practical prompt assembly from retrieved context windows

## Features

- Semantic retrieval over podcast transcript chunks
- Context-aware responses generated by OpenAI chat completions
- Web UI for interactive querying
- REST endpoint at `POST /query`
- Docker setup with persistent Redis data and auto-restore logic

## Tech stack

- Python 3.12
- Flask
- OpenAI API
- Redis Stack (RediSearch vector index)
- Pandas / NumPy
- Docker + Docker Compose

## Architecture (high level)

1. Transcript chunks and precomputed embeddings are loaded from `app/data/`
2. `docker-setup_vector_db.py` (or `app/setup_vector_db.py`) indexes vectors in Redis
3. User query is embedded in `app/utils.py`
4. Top-K similar chunks are retrieved from Redis (`embeddings-index`)
5. Retrieved context is appended to the system prompt and sent to OpenAI
6. Response is returned in the UI/API

## Quick start (Docker recommended)

1. Clone the repository and move into it
2. Create `.env` from template:

   ```bash
   cp env.template .env
   ```

3. Add your key in `.env`:

   ```bash
   OPENAI_API_KEY=your_openai_api_key_here
   ```

4. Start containers:

   ```bash
   ./docker-start.sh
   ```

5. If this is your first run, initialize vector data:

   ```bash
   ./docker-init-data.sh
   ```

6. Open:
   - App: `http://localhost:8000`
   - RedisInsight: `http://localhost:8001`

For full Docker operations, see `DOCKER_README.md`.

## Quick start (local runtime)

1. Create and activate a virtual environment
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Ensure Redis is running locally on `6379`
4. Ensure data files exist in `app/data/` (`embeddings.csv`, `title_dict.pkl`, `chunk_dict.pkl`)
5. Build the Redis vector index:

   ```bash
   cd app
   python setup_vector_db.py
   cd ..
   ```

6. Run the app:

   ```bash
   ./run_app.sh
   ```

See `QUICKSTART.md` for a concise local workflow.
